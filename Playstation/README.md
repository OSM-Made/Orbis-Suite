# OrbisAPIDaemon
API Interface for remote control of a jailbroken PS4 console.

# Build Requirements
- PS4 Official SDK
- [7-Zip](https://www.7-zip.org/)

# Build Instructions
1. Build all of the dependencies in the `\Playstation\External` folder.
2. Update the path to the 7z executable if needed depending on your installation.
3. Build the `OrbisAPi.sln`.
4. Build the pkg using your choice of tool.
